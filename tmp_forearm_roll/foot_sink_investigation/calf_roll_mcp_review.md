## 2. 证据链：滚转在哪一步首次出现

1. **FK 阶段为零（实测+复算）。** 小腿 FK 朝向只做最短摆幅对准链方向
   （`retarget.py:590-593`；链扭转只对躯干与前臂开放，
   `_use_chain_twist` 389 行，腿不在列）。用插件公式在现场逐帧复算 FK
   小腿朝向，其世界滚转 8 个采样腿-帧全部为 0.0°。父骨骼也不是来源：
   目标右大腿世界滚转仅 -8.8…+6.3°，小腿 -68…-79° 不是大腿传下来的。
2. **两骨瞄准阶段产生（离线复算复现）。** `_solve_chain`（ik.py:393）→
   `_two_bone`（511）求膝/可达点 → `_aim_joint`（491）以
   `rotation_difference(当前链向, 期望链向)` 的最短弧先后摆大腿、小腿。
   该摆幅只定链方向，绕链轴的滚转是无约束自由度，由两次摆幅的轴合成
   （holonomy）被动决定。以 FK 朝向为起点、用烘焙膝位锚定极向复算：
   大腿摆幅 55–59°、小腿摆幅 74–79°（右腿 15–17 帧），复算滚转
   -70.5/-81.8/-80.9/-30.2°，与烘焙实测 -68.0/-79.4/-75.6/-21.3° 对应
   （残差来自目标/极向以烘焙结果回代的近似，膝位误差 0.012–0.046 m）。
   左腿 15/18 帧同样对应（-13.6 对 -18.4；-14.4 对 -15.9）。
3. **左腿 16/17 帧的近 180° 不需要翻转分支即可解释。** 同一复算在左腿
   16/17 帧给出 +138.6° 与 -141.3°（在 ±180° 缠绕带内与烘焙 +172.4/+146.0
   等价量级），其大腿摆幅达 77.8°/134.4°——链方向接近反向时最短摆幅的
   合成滚转天然冲向 180°。`_fold_opposes_bind`（ik.py:473）是否在这两帧
   实际触发，离线第一遍复算（极向以烘焙回代）判为未触发，但该复算的
   极向与烘焙时不完全一致，故触发与否**证据不足**；可确定的是：翻转
   不是该异常的必要条件。右腿渐进滚转（摆幅合成）与左腿近翻转量级
   滚转（大摆幅几何）机制同类、程度不同，不是两个独立机制——与此前
   “右腿渐进/左腿翻转两个机制”的猜测不同，以本轮复算为准。
4. **来源 Twist 被忽略（代码确认）。** 来源小腿世界滚转约 +98…+108°
   （右，现场实测），其插件口径链扭转（`_source_chain_twist`）为
   +97.9/+100.2/+107.9/+102.2°；腿部 FK 不调用 `_twist_about_chain`
   （仅躯干/前臂），IK 目标只用链伸展比与踝点位置，来源滚转不进入
   任何腿部计算。

## 3. 与前臂问题的逐项对照

| 维度 | 前臂（已解决） | 小腿（本轮） |
|---|---|---|
| 滚转首次出现阶段 | FK 朝向传递：逐帧最短摆幅在近反向（约 174°）时滚转选边翻转 | IK 瞄准：FK 干净（0°），两次最短摆幅合成滚转 |
| 显式 Twist 处理 | 有：来源链扭转（相对旋转口径）+ 整段确定性缓存（Stage-6） | 无：腿既无来源扭转传递，也无滚转参照 |
| 典型失效帧 | 38→39 帧滚转跳约 130° | 左 16/17 帧约 +172/+146°，右 15–17 帧 -68…-79° |
| 求解器自由度 | FK 朝向的滚转自由度 | 两骨 IK 中小腿的滚转自由度（极向只定膝面，不定小腿滚转） |
| 连续性处理 | 整段预计算、与求值顺序无关 | 无；逐帧由该帧 FK 朝向与目标确定性生成（非历史状态） |

**根因分类：部分同源。** 共同根源是“用最短摆幅定方向时，绕链滚转这一
自由度没有显式参照来钉住”；不同在于出事阶段（FK 传递 vs IK 瞄准）与
参照的有无（前臂有来源扭转可传，腿部来源扭转约 100° 且骨架约定不同，
不能直接照搬）。此前的坐标空间错误（世界点喂给骨架空间接口）与本次
滚转无关，已在更早轮次修复且不在本轮证据链中。

## 4. 候选 A/B/C 的离线评估（仅数学计算，未写入场景）

- **A. IK 后恢复 FK 滚转（参照=FK 的 0°）：** 需在瞄准后绕最终链轴
  去滚转 -（烘焙滚转）：右腿 15–18 帧分别 +68.0/+79.4/+75.6/+21.3°，
  左腿 16 帧 -172.4°（等价 +187.6°）。能同时消除渐进滚转与大摆幅
  滚转，不改变踝位置与膝面；代价是小腿滚转被钉在绑定滚转，来源动作
  里真实的小腿内/外旋（约 100°）被丢弃，深屈膝时脚尖朝向只由踝
  旋转目标（足骨单独写旋转）承担。跨帧连续性最好（参照逐帧恒定）。
- **B. 传来源链 Twist（前臂同款）：** 以 `_source_chain_twist` 口径，
  右腿将得到约 +98…+108°、左腿 +21…+54° 的目标滚转（15–18 帧），
  替换当前 IK 滚转。它保留来源表演意图，但两副骨架的绑定滚转约定
  不同（来源小腿骨本地帧与 Bip01 相差约 90° 级），数值不能直抄，
  需先做绑定滚转差校准；且来源滚转在深蹲段本身变化快（左 54→33°），
  跨帧连续性需另行验证。风险最高、最接近“换一个参照”而非“去滚转”。
- **C. 只处理极向翻转连续性：** 仅影响 `_fold_opposes_bind` 触发帧；
  本轮证据显示左腿大滚转无需翻转即可产生，故 C 不能解决右腿
  -79° 与左腿大滚转的主体问题，只能作边角补充。

来源滚转校准实验；C 暂缓。
