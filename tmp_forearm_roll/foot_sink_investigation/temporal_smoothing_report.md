## 2. 三种策略（实现于副本 `ik.py`，两遍烘焙，计划为全序列预计算）

- A = S3 基线（无平滑）。
- B（T1）：修正向量两遍 [1,2,1]/4 二项平滑（边界复制延拓，非因果，
  第一遍烘焙记录全序列后构建计划，第二遍施加计划 + 原安全复核兜底）。
- C 原案（T2）：修正 Z 的联合求解 min Σ(c−raw)² + λΣ(Δc)²（λ=4 帧²），
  约束 c_z ≥ raw_z，active-set + Thomas 法；X/Y 无约束平滑。
- C 修正案（T3）：对**目标脚底高度轨迹**联合处理——期望最低点轨迹 =
  S3 逐帧反馈结果经同一二项核平滑并以地面容差为下限，超出原始结果的
  部分以附加抬高加入修正（修正从不减少，见 `build_height_plan`）。

参数依据：λ 与核均未按视觉选取。离线对修正序列求解表明，T2 在任何
λ（4/25/100/400）下 16–18 帧均为约束激活峰值，最大修正步进恒为
0.0744 m——修正空间平滑在数学上无法降低该落差，故提出 T3；
T3 的核与 B 相同（二项两遍），唯一自由度是核宽，未做逐案调参。
