## 一、根因及证据

### 地面高度的声明语义与实现语义不一致

UI 把它定义为世界坐标：`__init__.py:508`
`foot_floor_height_m`「世界空间地面平面的高度（米）」，在 `:254` 传入
`FootIKSettings.floor_height_m`，面板在 `:988` 显示（且不受地面约束开关影响）。

实现却把它当作两个角色共用的运动空间零点：

- `motion_space.py:55-107` `build_motion_space`：`:98-100` 把空间原点的
  世界 Z 设为 `floor_height_m / meters_per_blender_unit`，于是每个运动空间
  都以「Z=0 位于配置地面」建立（文件头 `:1-6` 也是这样声明的）。
- `retarget.py:916-917` `_prepare_retarget_geometry`：来源空间和目标空间
  用**同一个** `settings.floor_height_m` 构建。

后果是数学上必然抵消：踝目标生成（`foot_ik.py:182-217`
`generate_limb_goal`）传递的是来源踝相对其运动空间的高度；
来源在世界 0 接地、地面设 +0.05 时，来源脚底相对配置地面为 -50 mm，
目标就忠实地复现 -50 mm。这不是某处把偏移加了两次，而是
「目标地面」从未单独进入过计算：目标空间得到的与来源空间是同一个零点。

这与本产品的场景约定也冲突：来源角色按世界 0 接地
（站位布局与 `HR_Y0_Floor` 都在世界 0，`__init__.py:130-171`），
用户设置地面高度时，期望改变的是目标角色的接地面，不是重新定义来源的零点。

### 复查与高度计划用绝对世界 Z

- `ik.py:119-128` `_skin_lowest_world` 返回蒙皮点的**世界 Z**；
  `ik.py:199-209` `_recheck_foot_contact.measure` 直接使用它
  （无蒙皮时的备选分支 `:206-209` 同样取世界 Z）。
- `ik.py:40` 容差 `_CONTACT_FLOOR_TOLERANCE = -0.001` 是绝对世界高度；
  `:238-245` 的修正量按它计算，再加到运动空间的目标上。
- `ik.py:80-100` `build_height_plan` 把 `lowest_series` 当作运动空间高度做平滑；
  该数据来自 `retarget.py:2083-2088`，即 `CONTACT_LOG` 的世界 Z 记录
  （`ik.py:268-272`）。世界 Z 与运动空间高度只在地面 0 且角色位于
  世界原点附近时数值相等，属于隐含耦合。

### 附带影响

`foot_ik.py:220-248` `constrain_goal_floor` 在运动空间内工作，
其 `height = abs(source_end_z)` 在共用地面下是相对配置地面的高度：
地面 +0.05 时，接地的来源踝读作 0.045 m 而不是其离地高度 0.095 m，
衰减权重和目标高度的语义都随之漂移。

### 实测证据（上一轮）

`generalization_report.md` / `generalization_frames.csv`：
地面 +0.05 时脚底世界最低 -1.001 mm、相对设定地面 -51.001 mm（53/53 帧）；
地面 -0.05 时相对 +48.999 mm。脚始终落在世界 Z=0。

| # | 文件 / 函数 | 当前行 | 修改 |
| --- | --- | --- | --- |
| 1 | `retarget.py` `_prepare_retarget_geometry` | 916-917 | 来源空间以地面 0 构建（`build_motion_space(src, source_body, meters_per_unit, 0.0)`）；目标空间保持 `settings.floor_height_m`。来源地面即产品约定的世界 0，目标地面由设置决定，偏移只在目标侧应用一次。 |
| 2 | `ik.py` `_skin_lowest_world`（建议改名 `_skin_lowest` 并加 `space` 参数） | 119-128 | 对每个蒙皮世界点先做 `space.world_position(point).z` 再取最小，返回**目标运动空间**（地面相对）高度。唯一调用方是 `_recheck_foot_contact.measure`（`:205`），把已有的 `target_space` 传进去即可。 |
| 3 | `ik.py` `_recheck_foot_contact.measure` 备选分支 | 206-209 | 无蒙皮点时同样把世界点经 `target_space.world_position` 转换后再取 Z，保持两条测量路径同语义。 |

不需要改的部分及理由：

- `motion_space.py`：`build_motion_space` 本就按参数逐空间建零点，机制无错。
- `ik.py` `build_height_plan`（80-100）：`lowest_series` 改为运动空间高度后，
  它与计划向量（运动空间目标偏移）自动同语义，函数本体不动；
  `_CONTACT_FLOOR_TOLERANCE` 保持 -0.001，含义变为地面相对容差。
- `foot_ik.py`：`constrain_goal_floor`、`generate_limb_goal`、`plant_goal`
  都在运动空间内计算；来源空间改回地面 0 后，`source_end_z`、
  `source_rest_end_height`（`retarget.py:1023,1036`）、接触速度采样
  （`retarget.py:1113-1125`）恢复为来源离地高度，语义自动修正。
- 骨盆：`retarget_pelvis_position` 与 `PelvisReference`
  （`retarget.py:946-967`）的源/目标静止高度改在各自空间取值后，
  比例自动包含目标地面偏移，公式不动。
- `height_offset`（`retarget.py:1035`）：`tgt_end.z - src_end.z` 中目标项
  含地面偏移、来源项不含，正是目标运动空间所需的踝高差，不动。
- 计划缓存：签名已包含全部 `ik_settings` 字段（含 `floor_height_m`，
  `retarget.py:1842-1846`）和双角色世界矩阵（`:1838-1841`），
  不同地面值不会误用缓存计划，无需改签名或版本号

- UI：功能不动。可选后续单独把描述改为「目标地面高度」并让

两个几何调用方（普通路径 `retarget.py:1912`、姿势通道路径 `:1333`）
共用 `_prepare_retarget_geometry`，修复点一处覆盖两条路径；

## 三、修改前后的坐标处理逻辑

以地面 +0.05 m、来源踝世界高 0.095 m 为例：

```text
修改前（共用零点）
  来源运动空间 Z0 = 世界 0.05 ─┐
                               ├─ 来源踝运动高 0.045 ─> 目标踝运动高 0.045
  目标运动空间 Z0 = 世界 0.05 ─┘        └> 目标踝世界高 0.095，脚底在世界 0
  复查：世界 Z 对 -0.001（与设定地面无关）

修改后（目标地面单侧应用）
  来源运动空间 Z0 = 世界 0（产品约定）─> 来源踝运动高 0.095（真实离地高度）
  目标运动空间 Z0 = 世界 0.05 ─> 目标踝运动高按 0.095 传递
        └> 目标踝世界高 0.145，脚底落在世界 0.05 的地面上
  复查：目标运动空间 Z 对 -0.001（即脚底 >= 地面 -1 mm）
```

地面 Z=0 等价性：地面为 0 时，修改 1 的来源空间与现状逐字相同；
修改 2 中运动空间 Z 与世界 Z 相等（原点世界 Z 为 0、上轴即世界 Z，
`motion_space.py:79-100`），复查与计划的数值不变。
因此四个已验证动作的回归结果必须与 1.7.5 基线一致，这是硬性验收项。

## 五、潜在风险及回滚

风险：

1. 来源地面约定：如果某个来源动画本身不在世界 0 接地（例如来源自带平台），
   地面非 0 时其离地高度会按世界 0 重新解释，与 1.7.5 的旧行为不同。
   地面 0 时完全无影响；建议在发布说明中写明「地面高度指目标接地面、
   来源按世界 0 接地」。
2. `CONTACT_LOG` 第 4 字段语义由世界 Z 变为地面相对高度。
   已核查其唯一消费者是 `retarget.py:2083-2088` 的计划构建；
   外部调试脚本若按世界 Z 解读需同步知悉。
3. 姿势通道路径共用几何构建：普通路径回归之外必须做通道冒烟测试。
4. `HR_Y0_Floor` 显示仍固定在世界 0（`__init__.py:130-171`），
   非零地面时视觉地面与实际接地面不一致。本次不改，列为已知 cosmetic 缺口。
5. 平移不变性 T3 的衰减敏感性：`constrain_goal_floor` 的 0.08/0.20 m
   衰减带按来源踝高计算，整体平移后权重变化，膝角可能有小幅差异；
   已在测试矩阵中单独放行姿态、但不放行脚底标准。

回滚：

- 实施前把正式目录的 `retarget.py`、`ik.py` 另存副本并记录哈希
  （归档值见本文头部；注意现有 `backup_official_1.7.5` 只含
  `ik.py` 与 `__init__.py`，不含 `retarget.py`，实施时必须补齐）。
- 修改只涉及上述两文件三处；回滚即恢复这两份文件并核对哈希，
  版本号回退（按既定规则，合并修复时版本升到 1.7.6，回滚则恢复 1.7.5）。
- 副本验证不过或 F0 与基线不一致时，不合并，直接丢弃副本。
