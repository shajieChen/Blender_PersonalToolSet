# 人形装备三步操作与首次设置设计

```text
选择角色 -> 选择装备 -> 放到指定位置
缺角色握位 -> 设置并保存一次；缺装备拿法 -> 摆好并记住
```

日期：2026-10-30。状态：设计与逻辑实施已验证；Visual、真实Undo/Redo和用户资产待人工复核。目标是让日常装备无需理解骨骼、Empty、挂点或父逆矩阵。范围只包含现有五部位刚性装备，不增加自动握拳、双手IK或导出。

## 当前事实与最小修改

当前源码已有最终角色映射、create_mount、prepare_grip_root、bind_weapon、equip_weapon、ParentPose 和失败恢复。截图中的头部与右手挂点混显，来自保存的 mount 指针未按当前角色/部位筛选；旧 status 也会持续显示。只调整交互归属和首次设置，继续使用既有矩阵实现。

## 界面和状态

主界面固定显示“角色”“装备”“位置”和一个主按钮。位置使用下拉框，按钮明确显示“放到右手”等目标。选择装备是显式动作，角色不会随视口选择跳变。角色未选时提供“使用重定向角色”；已选角色保留原选择。多部件装备在点“使用选中的物体”时固定部件集合，后续编辑角色握位不会丢失装备输入。

已有旧子面板全部置于新的单一“高级设置”开关之内，默认关闭。旧文件的子面板展开状态不改变主界面。高级入口保留骨骼选择、多个安装位置选择、改名/复制/删除、保持位置绑定和详细数值。

| 当前条件 | 唯一下一步 |
|---|---|
| 未选角色 | 选择角色 |
| 未选装备 | 使用选中的物体 |
| 缺映射或位置失效 | 说明原因，在高级中修复 |
| 同部位多个挂点 | 选择该部位安装位置，不显示其他部位旧值 |
| 缺角色握位确认 | 设置角色握位 |
| 缺装备握持根 | 设置装备拿法 |
| 两者有效 | 放到指定位置 |
| 已装备 | 调整位置 / 取下 |
| 设置进行中 | 保存 / 取消，其他入口锁定 |

状态查询只读当前数据，不创建对象、不更新依赖图、不写保存字段。放置目标与装备当前所在位置分别表达；例如选择头部而剑仍在右手时，提示“当前在右手，取下后可放到头部”，取下按钮明确显示来源。已装备按钮禁用以避免多余点击，底层接口保留幂等重复调用兼容。不在主面板显示过期的 status；必要操作结果用即时 report，详细原因仍可在高级查看。

## 角色握位与装备拿法

已有挂点不等于已校准。新增 hm_grip_fitted 标记只由“保存角色握位”明确写入。旧挂点默认需要确认一次，保留其当前偏移，不重置。reset/reanchor 后取消确认，避免误称已设置。

角色设置：从当前有效挂点或自动映射创建一个点，选中原生标记；用户移到掌心或目标装备位置后保存。新建点取消时只删除本次点；已有点取消时恢复所有进入前的变换。移动角色点会预览影响其附件，取消也恢复该影响。

装备设置：选择已固定的刚性部件，让用户直接移动/旋转到正确位置。“记住当前拿法”用已校准角色点的世界矩阵创建握持根，保留部件世界姿势后绑定。没有光标步骤。已登记装备调整时，只重设装备根与部件的握持关系，角色点不变。保存失败恢复保存入口姿势并保留设置状态供重试；取消恢复进入设置前姿势。取消前校验全部快照字段和对象；恢复中途失败则回到取消入口的编辑姿势并保留快照，不能留下半恢复状态。

## 数据和职责

properties.py 保存明确选中的装备、部件Object指针集合及正在进行的设置状态。新增 EquipmentObject 只保存对象和其原父级指针；设置快照保存原生通道、父级类型/骨名、父逆矩阵与旋转模式，不按名字查回对象，不依赖隐式全局缓存。

placement.py 负责当前步骤查询、输入选择、设置开始/保存/取消。weapons.py 保留装备绑定与握持根校准机制；mounts.py 保留挂点归属和部位选择。operators.py 是唯一界面动作入口，panels.py 只画界面。依赖为 panels/operators -> placement -> weapons/mounts/properties；不反向导入，不依赖重定向私有函数。

设置由 Scene.hm_settings 拥有，同一场景只允许一段。开始/保存/取消均是Undo算子；禁止自动切模式、Auto Keying、不可编辑或隐藏/禁止选择对象进入设置。保存blend后重开仍能取消；停用插件先检查所有场景的恢复记录，通过后再取消未保存设置并注销属性。恢复失败明确报错，不销毁恢复证据或静默完成。原生父级在停用后继续有效。

## 取舍与变化边界

推荐原生控件和原生移动/旋转工具。仅折叠旧面板不能解决首次设置；每次弹完整向导增加重复操作；人体图形选择器及通用工作流框架均不进入本次。以后增加部位只扩展现有部位定义；换武器只更改武器拿法；换角色只更改角色握位，均不修改绑定核心。

风险集中在跨步骤编辑的取消与保存、旧校准兼容和多角色选择。用快照及创建者标记限制回滚范围，禁止猜测掌心或剑柄。当前骨骼坐标与任意武器握柄无法单凭骨名准确反推，因此只对已校准资产承诺日常一键。
