## 目标与边界

在 Blender 的 3D 视口直接控制已绑定角色：方向键走，按住左右任一 Shift 跑，松开方向键待机。角色必须真实移动并播放对应动画。提供可保存、重开、跨文件载入的动画库，后续在同一插件中增加 Motion Matching。

独立插件 `character_locomotion/`，侧栏为“角色操控”，首版 `1.0.0`，当前兼容修复版 `1.0.1`，列表名称为字面量 `Character Locomotion v1.0.1`，主面板标题从 bl_info 版本生成。现有重定向插件负责导入、映射和动画准备；新插件负责操控、片段库和播放。两插件不互相导入私有模块，停用重定向插件后仍可使用已准备的动画。2026-11-12 用户已授权按本文与实施档实施；不改旧插件业务代码或版本。

本期完成单角色、水平移动、转向、待机走跑切换、短过渡和动画库。碰撞、重力、跳跃、斜坡、录像、网络、自动跟随相机及 Motion Matching 搜索算法不在本期。脚部滑动需通过片段标称速度与播放速率匹配控制；不承诺接触锁脚。

## 职责与依赖

```text
__init__ 注册与面板
   +-> locomotion.py        输入、会话、位移、退出
   +-> animation_library.py 片段登记、验证、库读写
   +-> animation_playback.py NLA 时间、权重与恢复
既有重定向工具 -> Blender Action 数据块 -> 新插件动画库
新插件运行时不导入重定向插件私有模块
```

这三个文件是按业务职责划分的新增文件。面板只调用入口，不在 draw 中扫描磁盘或修改场景。移动计算使用普通数值和小型具体记录；不引入通用状态机框架、选择器注册表或新的外部依赖。所有 bpy 读写在主线程；一场会话只有一个角色写入者。

2026-11-12 局部模块地图（Static，源码未提交）：`__init__.py` 注册、页面及操作入口 --calls--> `locomotion.LocomotionSession`；会话 --owns--> timer/播放器，--writes--> 当前角色对象变换；会话 --calls--> `animation_library.validate_clip_steps` 和 `animation_playback.CharacterPlayback`；播放器 --calls--> 库的槽位读取，--owns--> 临时 Action 副本/两条 NLA 轨道。库 --reads/writes--> 角色上的片段、稳定绑定和自包含文件。依赖方向为 UI → 会话 → 播放/库、播放 → 库，无反向 import；共享入口只有显式活动会话引用，所有 bpy 调用在主线程。验证入口和未知项集中在实施进度，不另建重复地图。

`LocomotionSession` 持有按键集合、时钟、角色借用引用、入口快照与本次 NLA 资源身份。模块只保存一个可显式清空的活动会话引用，用于阻止重复启动及注销清理；不是持续运行的全局业务状态。注册不启动 timer，只有用户点击开始才创建会话。

1.0.1 新增已核验的可选边界：`locomotion.validate_character` --reads--> 已加载 `spring_bone.operators` 的 `job_running()/active_session()` 公共入口；同一 armature 正在实时预览或烘焙时，在修改 Action 前拒绝启动。动态骨骼任务仍由原插件拥有，操控插件不自动停止、重启或接管它；不引入私有模块 import、每帧跨插件轮询或通用注册表。其他第三方动画写入者仍需独立核验，不能从这一个保护推断全面共存。

## 操作与移动合同

### 三步引导页面

使用 Blender 原生 N 侧栏，不另建网页或弹窗向导。常用路径保持在一个主面板；动画库管理和高级设置默认折叠。以下为布局示意，状态以文字和图标同时表达，不只靠颜色。

```text
+--------------------------------------------+
| 角色操控 v1.0.0                            |
| 1 选择角色                                 |
| [使用当前选中角色]  角色 [搜索骨架...]      |
| 2 准备动画              [载入动画库...]    |
| 待机 [选择动画...]       [预览]            |
| 行走 [选择动画...]       [预览]            |
| 跑步 [选择动画...]       [预览]            |
| 提示：还缺跑步动画，请选择一个跑步片段     |
| 3 开始操控                                 |
| [检查并开始操控]                           |
| 方向键走 / Shift 跑 / Esc 停止并恢复       |
| 本次为预览，停止后回到开始的位置           |
| > 动画库管理                              |
| > 高级设置                                |
+--------------------------------------------+
```

- **选择角色**：“使用当前选中角色”接受骨架或蒙皮网格，只在点击时解析当前选择。网格的骨架父级与 Armature 修改器引用合并后只有一个候选才绑定；零个或多个候选显示原因并要求从原生骨架搜索器明确选择。绑定后固定目标，用户选中装备或旋转视图不自动换角色。已有有效配置打开即显示，不重复向导。
- **准备动画**：每行以中文用途展示可搜索的兼容片段，默认全片段范围；已有带用途的库中每类只有一个兼容片段时可自动回填空槽，绝不覆盖手选绑定。当前文件 Action 通过行内选择登记，用户只需确定用途。仅按文件名、骨名或名称含 walk/run 不能认定兼容和用途；模糊匹配只作建议。
- **检查并开始**：缺角色或缺动作时按钮不可用，同时在面板显示首要原因与可执行下一步；基础条件齐备时按钮可点，点击后执行完整骨架、槽位、原地性、竞争写入和数值检查。失败留在原页，定位相关行；通过后在所属 3D 视口开始。选择“预览”只原地播放该片段，使用同一播放器与恢复入口，再次预览先结束上次，互斥于角色操控。
- **操控中**：主区域显示“待机/行走/跑步”与“停止并恢复”，禁用换角色、编辑片段和库读写。视口显示“将鼠标移入视口后按方向键”；移出或失焦显示“已暂停，返回后重新按键”，禁止残留按键自动继续。停止后恢复配置页面及入口姿势、位置。

三步表示任务分组，不承诺三次鼠标点击完成任意素材准备。已确认元数据的兼容库可直接回填；首次 Action 登记用一个简短确认区展示用途、素材帧率及循环范围，确认状态随片段保存，重开不反复询问。预览只检查目标角色与该单个片段，不以另两行未配置为由阻止预览。主按钮文字和位置固定，检查过程暂显“正在检查，可取消”；取消与失败都不得建立半成品会话，完整校验应分批在主线程推进以保持界面响应。

### 默认值与错误修复

默认走速 1.5 m/s、跑速 4.0 m/s、过渡 0.15 秒；前向暂取 +Y，旁边提供“面向不对？”入口展开四向选项，由用户用短预览核对，不能猜测 FBX 前向。默认帧率取当前场景但标记“暂用场景帧率”，首次登记未知采样率素材时需确认或修正；未重复末帧的素材需确认循环范围，不能声称已自动消除滑步或接缝。

高级设置收纳源/播放 Action、槽位、帧范围、素材帧率、循环周期、标称速度、前向和过渡；当前阻断项涉及哪个字段，就显示哪个简短修复入口，其余保持折叠。多槽用可读名称下拉并在内部保存 identifier，不让用户手填内部 ID。空白槽位和失效引用不得静默回退到首槽。

| 情况 | 页面说明 | 下一步与失败边界 |
|---|---|---|
| 空场景或未选角色 | 先选一个角色骨架或蒙皮网格 | 使用当前选择或搜索骨架 |
| 多骨架候选 | 找到多个骨架，请指定操控对象 | 列出候选，不自动修改选择或父级 |
| 缺动作 | 还缺待机/行走/跑步动画 | 对应行选择动作，或载入动画库；不让缺失动画静默沿用其他状态 |
| 根运动或约束竞争 | 当前动画不能直接操控，请先准备原地动画 | 展示既有“重定向”侧栏的准备步骤；不执行破坏性自动修复 |
| 同骨架动态骨骼任务正在运行 | 请先停止该角色的动态骨骼实时预览或烘焙任务 | 用户在“动态骨骼”关闭“实时预览”后再操控；插件不暗中停止或共享同一骨架写入权 |
| 骨架不匹配 | 这个片段需要先重定向 | 保留片段供浏览，禁止绑定播放 |
| 素材帧率或循环未确认 | 请核对素材帧率/循环范围 | 展开对应字段，修正后重试 |
| 载入失败或取消文件选择 | 未载入动画库，当前配置已保留 | 显示原因与重试入口，不清空已配动作 |

“准备动画”说明复用现有重定向侧栏的“导入含动画的模型”“重定向到当前目标”和“原地”选项；新插件只提供就地步骤说明，不调用会烘焙或修改骨架的隐式一键操作。重定向插件未启用时解释启用方式，不自动安装或启用。当前库列表支持名称/用途筛选；保存与载入使用原生文件选择器，默认记住上次成功位置。移除按钮写“移除库条目”，并说明保留原始动画。

### 页面职责与配置保存

页面状态来自已有角色配置、库条目、活动会话和校验结果，不另建向导状态机。`__init__` 只展示并调用三个业务模块；角色与动作引用及速度配置随当前 blend 保存，折叠状态与最近目录属于界面偏好，按 Blender 现有机制保存。稳定 ID 是绑定身份，改显示名不丢配置。

角色指针归 Scene；片段集合及 idle/walk/run 的 clip_id、速度与前向归角色 Object；片段保存帧率来源与时间范围确认状态。校验缓存和活动会话不持久化，最近成功目录归插件偏好，不写死机器路径。更换目标先结束预览，再读取新目标自己的配置；旧角色绑定保留但不迁移。清空、删除或失效的原绑定显示“需重新选择”，禁止当作首次空槽自动补入另一动作。只有首次未配置的槽允许唯一候选回填；手动清空代表用户意图。

draw/poll 只读取轻量状态；完整曲线/骨架校验由显式登记、载入或检查动作在主线程执行。结果缓存绑定角色、库条目与影响字段，相关变化显示“需要重新检查”；开始前必须重新验证，不能凭绿色旧结果启动。大量片段不在每次绘制中全扫描。此处是拟新增页面契约；已有模块事实仍以“当前事实与复用点”为准。

使用流程：选角色骨架 → 登记或载入动画 → 指定待机、走、跑 → 点击“开始操控” → 鼠标留在 3D 视口操作 → Esc 或“停止”恢复入口状态。操控是可恢复预览，不保存运动轨迹、不插关键帧、不永久改变角色落点。

- 上下左右使用实际方向键。启动时把视口前向投影到世界 XY，得到“上”；右向与它正交。会话期间固定该基准，旋转视口不突然改变已按住的方向。顶视投影退化时使用世界 +Y，并显示当前基准。
- 相反方向抵消，斜向归一化，速度不增加。方向指向行进方向，角色转身后向前走；“下”表示朝后方行进，不是倒走动画。
- 仅有 Shift 时待机。左右 Shift 任一按下均跑，释放其中一个但另一个仍按住时继续跑。松开全部方向键立即停止平移并过渡待机。
- 速度按米/秒表达，结合 `scene.unit_settings.scale_length` 换算 Blender 单位；走、跑初值建议 1.5 和 4.0，可调且必须有限、正值、跑大于走。朝向轴由用户选择角色本地水平轴，不能假定所有 FBX 面向一致。
- timer 目标间隔 1/60 秒；位移按单调时钟实际 dt 计算，最大 dt 0.05 秒，超出部分丢弃以避免卡顿后瞬移。不同帧率不改变正常累计位移；限幅属于明确暂停语义。
- 只处理自身 timer 的推进。Blender 5.1.2 实验中 Event 没有 timer 属性，禁止使用 event.timer；参考相机插件比较所持 timer 的 time_duration 是否推进，并实测外来 TIMER 不重复积分。方向键与 Shift 被会话消费；编辑、删除、时间轴播放及会改变角色的快捷操作被阻止。普通视图旋转/缩放可放行；已有飞行、变换、烘焙等冲突 modal 时拒绝启动。
- 失去窗口焦点或移出所属视口时清空按键并暂停；返回后需重新按键。切工作区、切场景、原视口关闭、角色被外部删除、切文件、异常或注销时结束会话并在原 owner 上恢复仍有效的入口数据，不改新场景。停止后按键恢复 Blender 原生行为，不新增全局方向键 keymap。

启动要求本地可写 Armature、无父对象、正且均匀的对象缩放、未进入 NLA tweak、时间轴停止。对象变换驱动、未烘焙的骨骼约束/驱动等会竞争写入的输入先拒绝，并提示沿现有流程烘焙到干净目标骨架。骨骼挂载子物体正常跟随，不改其父级和校准。这个边界必须在面板中明确，不能静默“运行但不动”。

不能只靠约束、驱动和 modal 列表排除竞争：当前真实场景的动态骨骼实时预览使用 app timer，也会持有并移除自有临时 Action。1.0.0 未阻止双 owner，已由 1.0.1 的前置门修复。MCP 复测期间此冲突导致动态骨骼自取消；其原始来源 Action 保留，已用原入口重建实时副本并恢复任务。物理积分历史重置，不声称完全复原原运行时身份与历史。

## 动画库合同

基础单位是完整 Action 的一个有界片段和明确 Action slot，不是单帧姿势资产。提供列表、名称过滤、类型过滤、登记、移除库条目、预览、保存库、载入库，以及三个角色动作槽位。移除条目只解除引用，不全局删除 Action。

| 记录 | 必需内容与原因 |
|---|---|
| 库 | 整数 schema、稳定 library_id、片段表；拒绝未知 schema，避免猜读 |
| 片段 | 稳定 clip_id、显示名、Action 引用、slot identifier、起止帧、原始 fps 与来源、循环周期、时间参数确认状态、用途 IDLE/WALK/RUN/OTHER |
| 播放 | 原地播放 Action 与源 Action 分开引用，各自记录 slot identifier；是否循环、标称米/秒；走跑标称速度必须大于零 |
| 骨架 | 骨名、父子关系、rest 矩阵与骨长、语义映射、角色前向与单位；用于兼容校验及后续离线采样 |
| 溯源 | 可选来源文件相对路径和源片段关联；保存根运动原片段，不能只剩去位移版本 |

记录由角色的持久属性与 Action 指针持有；字符串标识用于序列化及重名检查，运行时不反复按名称找 Action。默认帧率取登记时 scene fps/fps_base，必须显示并允许按资产真实采样率修正，不能声称从 Action 自动读到了原始 fps。

周期采用显式正的 period_frames：默认 end-start，表示末帧是下一循环的首姿势；未重复末帧的数据由用户设置周期并验证接缝。片段时长、采样率、非空通道、骨名、槽位和骨架匹配必须验证。骨架匹配比较 rest 矩阵和骨长，固定容差 1e-5；不能仅凭骨名或 rest 矩阵相同通过。仅改变末端骨长也必须拒绝。多槽无法唯一判定时要求选槽。

当前文件可直接登记已有 Action。外部库为自包含 `.blend`：保存库专用参考骨架、元数据与被引用 Action，通过 Blender libraries 写入/追加。元数据放在参考骨架上，避免 `.blend + 外置 JSON` 的双文件提交。先在同目录写临时文件，校验成功后原子替换；已有文件覆盖必须明确选择。导入仅追加库声明数据，不执行库内脚本，不改变活动场景和当前绑定；失败只释放本次新载入数据。按 clip_id 去重，同名不同 ID 显式消歧，动作绑定使用稳定 ID。跳过的追加数据和专用参考骨架必须回收，不能因假用户标记留下泄漏。

场景中的库路径使用 Blender `//`，以当前 blend 所在目录解析；未保存场景先要求保存或通过文件选择器确定基准。库内部来源相对路径以库文件目录解析，不能依赖工作目录。运行数据自包含，因此来源文件搬走后已保存片段仍可播放。界面显示来源丢失，但不删除数据。

FBX/BVH/glTF 动作继续使用现有来源导入及重定向，再登记结果；不新增第二套导入和重定向。不同骨架的库可浏览和保留，播放前必须先重定向。不会自动凭名字给任意角色直接赋值。

载入分开检查库结构完整性与角色播放兼容性：未知 schema、缺失声明数据拒绝载入并回滚；合法但异骨架的片段正常保留，标记“需重定向”，不得回填或播放。主页面只列当前已检查兼容片段，并显示其他片段数量及“查看不兼容片段”入口。相同 clip_id 且内容一致才去重；同 ID 的关键内容不同则报告冲突并取消此次载入，保留原库与绑定。单个外部库保持一种目标骨架；“保存当前角色动画库”只导出该骨架分组，保存前列明包含/排除数量，异骨架条目留在当前 blend，不冒用当前角色 rest 数据，不标记排除项已导出。载入库不等于导入 FBX，不要求新建第二套导入器。

## 播放与恢复

位移唯一由操控会话写角色对象。播放唯一由 `animation_playback.py` 通过临时 NLA tracks/strips 交给 Blender 动画系统求值；不每帧写骨骼矩阵，不推进全场景时间轴。会话开始前保存 Action/slot、NLA use/solo/mute、对象变换、pose 通道、场景帧及子帧、选择和模式等实际会触及状态。

操控用已验证的原地动画；根部水平位移、转向或对象变换动画未清除时拒绝播放，保留源片段供以后采样。不在循环里同时执行根运动和速度积分。验证需覆盖整个片段与接缝，不能只看首尾净位移为零。

临时 NLA 轨道覆盖入口场景帧。片段时间由会话秒数乘各自 fps 后映射到片段范围；循环按 period_frames 取模。设置明确 slot、REPLACE、手动时间及手动 influence，禁用自动 blend 时间；原有 tracks 临时静音、解除 solo，入口 Action 暂离，退出逐项恢复。目标走跑的播放速率为当前移动速度/片段标称速度。

走跑在切换时传递归一化周期相位，默认 0.15 秒过渡，闲置切换从片段起点开始。过渡时底轨为上一姿势流且满权重，上轨为目标并将权重从 0 升到 1；快速反复切换应以当前混合姿势建立会话自有过渡源，不允许叠加无限轨道。接缝与过渡必须用真实求值骨骼验证，不能把权重数值通过当成 Visual 通过。

**实施风险门**：NLA 手动时间、槽位、混合与固定场景帧下的重求值需在首批真实 Blender 夹具验证。RNA 定义只证明 API 存在，不证明这条播放链已经可用；失败先修复这一局部路径，不自动改为推进全局时间轴或自建骨骼动画器。

实施核验：Blender 会重求值 NLA influence。当前实现用会话自有 strip influence 曲线驱动权重，切换时采集当前混合姿势作为过渡源；原始 Action 只读，临时副本补齐未覆盖通道。根骨平移按骨骼 rest 轴与对象变换投影到世界 XY 后判断，不按 location 通道编号猜测水平/竖直。对应 RED、GREEN、真实骨骼过渡中点与快速切换测试已保存；当前校验保守拒绝带水平分量的变化通道，不支持抵消型多通道竖直组合或根旋转动画。

Esc、停止、异常、load_pre、unregister 共用幂等结束入口：先停止 timer 和回调，再删除本次 tracks/过渡 Action，恢复仍有效的入口数据，最后清空会话引用。不得删除用户 Action、清空全体 animation_data 或按名称前缀批量清理。预览中阻止保存；外部保存入口需经 save_pre 恢复会话后再写文件，确保临时 NLA 不落盘。外部 Undo/Redo 必须先结束预览；不依赖 CANCELLED 自动恢复。

## Motion Matching 接续边界与取舍

后续可从源片段、fps、范围、骨架和根运动数据离线采样姿势、速度、脚接触及未来轨迹。本期只保证这些原始数据可追溯，不提前固定特征向量维度、搜索索引、权重配置或神经网络依赖。未来由选择逻辑返回具体片段与时间，复用本期播放器，角色位移仍只有一个 owner。

三项变化推演：增加转身/起停动画只增加 OTHER 条目及未来选择规则；增加异骨架素材走既有重定向后登记；改成 Motion Matching 只替换待机走跑选择逻辑并增加离线特征生成，不修改库中原始动画或重做输入。三者都不要求现在增加抽象接口。

采用独立新插件满足用户要求，代价是增加注册与安装入口；动画准备复用现有工具，不复制导入和重定向。不扩展重定向插件，避免交互操控与离线烘焙耦合。不修改相机插件，其职责是视口导航。不用单帧 Pose Library 代替动作库，不以全场景 frame_set 驱动单角色。临时 NLA 的状态恢复与快速切换必须实测。
