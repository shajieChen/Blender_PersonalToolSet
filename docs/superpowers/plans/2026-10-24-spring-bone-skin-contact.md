# 裙面防穿与 FBX 骨骼动画修订实施档

## 目标

保留原静态裙长、八条四节模拟链和已修订的末端权重。修正真实裙面与腿/脚的穿插，结果只依赖骨骼 Action，可随普通动画 FBX 导出。保持旧 Action 可回退。

## 修改范围

- `spring_bone/solver.py`：胶囊端帽使用真实球面法线。
- `spring_bone/animation.py`：修正动作副本中相邻四元数键的符号；不改用户输入 Action。
- `spring_bone/skin_collision.py`：线性蒙皮预测、三角形相交检查、受限骨骼姿势搜索。
- `spring_bone/contact_bake.py`：主线程采样、原生蒙皮复核、新 Action 写入、取消与失败恢复。
- `spring_bone/properties.py`、`operators.py`、`panels.py`、`__init__.py`：每角色网格配置、独立“裙面防穿”操作，复用既有单作业调度和绘制。
- `humanoid_retarget/retarget.py`：只在写键处保持相邻四元数同半球，不改变映射、IK 或整帧姿势。
- `humanoid_retarget/pipeline.py`：普通 FBX 导出读取动作的通用 `fbx_sample_step`，默认仍为 1；无 Spring Bone import。
- 相应聚焦测试、场景验收脚本及本目录证据。保留其他任务已有的 A-Pose、挂点、安装脚本修改。

## 实施步骤

1. 材料已读：原公式证据、设计档、实施档、handover、四节末端权重结果、coverage-review/result.md。复用已读结论，仅在本次差异或证据冲突处重读。直接阅读实际修改代码。
2. 单批探子：几何算法与 Action/会话生命周期独立核验，返回 file:line；主执行者核对并修复尺度阈值、外部 Action 切换、已删除目标、模式和 Slot 边界。探子不改代码。
3. 先取得 selected-positive RED：胶囊端帽残余、三角形内部穿插、旧动作反号四元数、FBX 丢失半帧、Retarget 写键跨半球。再最小修复并转 GREEN。
4. 先验证单个困难帧，保存参数和失败证据；再执行完整动作。真实模型以 0–52 帧、身体腿/脚区域和真实裙面三角形复核，不能以骨尖或有限数替代。
5. 输入 Action 副本先修符号；关键帧旋转姿势保持等价，中间帧修复错误翻转。裙面修正优先保留原旋转，必要时仅调整模拟骨旋转和链首位移。位移有上限，不改静态骨架、骨长、网格顶点或权重。
6. 先生成并验证 0.5 帧结果，再复用该结果补到 0.25 帧；这是对已观测中间帧穿插的加密，不重复物理模拟。将所有修正写入独立 Action，原动作不覆盖。
7. 编译前检查：本次仅 Python/Markdown，无 C++ 构建入口。核对 Blender 5.2.1 的 Action/Slot、Bone 继承、线性蒙皮与 FCurve API；AST/编码/差异检查后运行 `tests/run_spring_bone_tests.py`，另跑四元数写键、A-Pose 动画导出和 Retarget 回归。错误先保留日志并修复，不以 selected=0 或非零退出作为通过。
8. 用普通动画 FBX 导出并回导，按片段相对时间对齐；记录 Blender 导入起点偏移。比较实际蒙皮和交叉数。随后用 BlenderMCP 在用户当前场景复核并展示。
9. 收尾顺序：完成目标并保存必要证据 → 用户核对实际画面 → 清理本次临时诊断 → 聚焦/回归及必要运行复验 → 最终完成报告。

执行效率复盘：初期只处理顶点/最近面法线会漏掉裙面内部相交；多次完整扫描由新发现的困难帧和错误四元数插值触发。之后固定保存失败姿势，先用该姿势验证，再全段扫描。一次验证脚本相对路径和一次错误过滤器已修正，相关失败不计 GREEN。0.5 帧结果直接作为 0.25 帧输入，避免重复已完成修正。

## 强制约束

- owner 为 `SkirtContactBakeJob`。Scene/Armature/Mesh 是借用；工作 Action 和未交付结果由作业拥有。成功移交结果，删除工作副本；取消、异常、加载、注销清除计时器和未交付 Action。
- 输入 Action/Slot、旋转模式、时间轴、帧率/单位、静态骨架、网格/权重变化必须失效。外部切换 Action 时保留新选择；只在仍持有本作业临时 Action 时退回原 Action。
- 仅支持同一目标骨架的无遮罩线性 Armature 蒙皮；拒绝形态键、DQ、包络、拓扑修改器、模拟骨约束/驱动及不能独立移动的连接链首。不能可靠预测时失败，不提交半成品。
- 碰撞部位由代理体绑定骨及其后代的身体蒙皮确定，包含脚；代理体半径不替代真实身体网格。此功能不等于布料自碰撞、体积保持或连续碰撞求解。
- 原生网格结果必须复核。数值预测误差门为 1e-5 米；输出采样点的实际裙面/身体三角形交叉为 0。安全间隙是求解目标，真实身体网格是验收对象。
- 目标角色使用 0.0002 米间隙。原 0.002 米间隙侵入本来贴身的腰部边界，不能强行拉开固定区域。保留用户可调参数及失败提示。
- 生成后仍为原生 Action 播放，不承诺网格修正生成阶段每单元低于 16 ms；最长阻塞实测并如实记录 Concern。无 bpy 工作线程、实时物理 handler、新通用框架或跨插件锁。不删除用户原 Action、物体或其他角色配置。
- 禁止新增代码注释；保留既有注释和无关差异。C/C++ 命名/格式、unique_ptr label、线程/ABI 等专项门均 NotApplicable。

| 层级 | 证据与门 |
| --- | --- |
| Static | 单向依赖；两个插件无互相 import；Retarget 只补写键与 FBX 采样两处相关接缝 |
| Contract/Process | selected > 0 的 RED/GREEN；故障、删除目标、Action/模式切换、多角色及 FBX 回导测试；进程自然退出 0 |
| Runtime | 原 Action 摘要不变；八条链均为四节；Rest 顶点及权重不变；采样实际交叉为 0；失败无结果残留 |

| Visual | BlenderMCP 实际场景检查裙面、腿和脚；不得只看骨骼或数值。保留前后图并等待用户核对 |
