# 按住鼠标中键时使用 WASD 移动视口实施档

## 目标

按用户最新确认：按住鼠标中键后，W/S 沿当前视线前进、后退，A/D 沿视口左右方向移动。视点与观察中心一起平移，不锁定 LookAt、不绕固定目标移动。松开中键立即停止；中键拖动继续用于旋转视图。

```text
中键按下 -> 当前视口接管 WASD -> 视点和观察中心同步平移
中键松开 -> 停止计时和移动   -> WASD 恢复 Blender 原有快捷键
```

日期：2026-10-27。状态：已获用户授权实施，功能及正式安装通过验证，用户已确认，清理后复验通过，实施完成。

### 中键在 Blender 中的含义

- 按滚轮是 `MIDDLEMOUSE`；滚动滚轮是另外的 `WHEELUPMOUSE/WHEELDOWNMOUSE` 事件。
- 当前 Blender 默认绑定为：中键拖动旋转，Shift+中键平移，Ctrl+中键缩放。在 G/R/S 等变换操作中，中键还参与约束操作，不能直接抢占。
- 中键不会自动把鼠标下的模型设为目标。普通视图围绕其观察中心旋转；本需求只让 WASD 同步平移这个中心与视点，不增加目标拾取。

依据：[Blender 5.1 导航手册](https://docs.blender.org/manual/id/5.1/editors/3dview/navigate/navigation.html)。本次还直接读取了用户 Blender 5.1.2 的有效键位：`view3d.rotate`、`view3d.move`、`view3d.zoom` 分别对应上述三种操作，当前旋转方式为 Turntable。

## 强制约束

### 移动与输入合同

- 用当前视图旋转计算前向 F、右向 R：`delta = normalize((W-S)*F + (D-A)*R) * speed * dt`。方向为零时不移动，斜向不加速。
- 只更新 `view_location += delta`。仅键盘移动时 `view_rotation`、`view_distance` 不变，因此由 `view_eye` 算出的视点也平移同一个 delta；W/S 不是缩放，A/D 不是围绕目标转动。速度复用原参数，单位为 Blender 单位/秒。
- 使用单调时钟的实际 dt，并将单次 dt 限制到 0.05 秒；长停顿丢弃超出时间，避免补跑造成跳跃。Timer 目标 60Hz，仅在自有 Timer.time_duration 前进时推进一次，不被其他插件通用 TIMER 事件重复推进；无按键时不写视图。
- WASD 的 PRESS/RELEASE 仅在中键会话内消费，重复 PRESS 不叠加速度；松开中键立即清空集合并停止 Timer。会话外不监听、不轮询键盘，不影响 A/S 等编辑快捷键。
- 新模式只接管普通 3D WINDOW 区域、当前已核对的 Turntable 操作。起始 Shift/Ctrl/Alt+中键保留原生；会话中按 Shift 使用现有 shift_multiplier 加速平移，松开恢复正常；Ctrl/Alt/OS 等其他修饰键仍暂停移动和拖动。左右 Shift 分别跟踪，释放其中一个不影响另一个。原生组合操作从下一次中键手势开始。
- 编辑 modal（尤其 G/R/S 约束）、界面控件、锁定视图、相机视图及 Trackball 不接管，保留原生处理；不自动改用户导航偏好或场景相机。普通自由正交视图使用同样的三维平移，W/S 不改变正交缩放，也不强制切透视。

### 所有权与兼容

操作器拥有 held 集合、入场视图快照、自己的 Timer 和临时 UI 状态；Window/Area/Region 是只在此次会话借用的对象。保持一个明确的活动导航引用，供停用、切换模式和注销时退出；不建立全局监听器或通用管理器。

中键释放保留最后视图；Esc/右键取消恢复入场视图。失焦、区域失效、异常和注销必须清理 Timer、按键状态、光标捕获和标题；区域已失效时不再写 RNA。清理幂等，只移除 `_ADDON_KEYMAPS` 中本包的条目，不删除共享 KeyMap 或用户原生键位。播放计时不应误判成编辑 modal，需在真实播放时验证。

所有 bpy 操作在主线程。保持旧模式数学和操作入口；最低版本按实际验收的 5.1.2 声明，不沿用尚未验证的新模式 4.2 支持承诺。不新增代码注释，不改无关格式；其他 dirty/untracked 工作保留。C++/ABI/unique_ptr 等专项 NotApplicable。

## 验收标准

| 检查 | 必须达到的结果 |
| --- | --- |
| 核心移动 | 按住中键并分别按 W/S/A/D，方向正确；中键不移动鼠标时也能连续移动；相反键抵消，斜向速度一致 |
