# 四节裙摆末端权重修订

```text
保留四节模拟 -> .002 下部权重平滑分摊至 .003 -> 下摆参与末节运动
```

用户明确选择保留四节模拟并重新分配裙摆末端权重，本记录取代此前三节链方案作为当前场景的选择。工作对象为BlenderMCP连接中的「骨架」和clothing；不修改Retarget、骨骼rest、动作曲线或其他角色。

## 修改

- 8条链均恢复根骨至`.003`的四节配置。
- 仅修改clothing的3215个下摆顶点。clothing.001的候选顶点不在下部区间，保持原样；身体、头发等其他网格不动。
- 沿各链`.002`的rest方向计算顶点位置，从该段35%处开始平滑分摊，至段尾达到最多80%的原`.002`权重。剩余权重仍由`.002`持有；其他骨骼权重不变，不做全局自动权重或归一化。
- 原Mesh数据块`tripo_mesh_910755f7`保留并设fake user。当前clothing使用独立副本`tripo_mesh_910755f7_SkirtHem`，原网格坐标与原权重哈希未变。
