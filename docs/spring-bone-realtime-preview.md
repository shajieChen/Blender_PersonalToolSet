# 动态骨骼实时预览

## 使用

在“动态骨骼”主面板中选择目标骨架，勾选“实时预览”。原生播放时每帧更新；暂停时仍会更新，修改链的重力、方向、刚度、拖曳、混合、碰撞半径即可生效。取消勾选或点击“停止预览”恢复进入前的Action，保留当前时间。

同时勾选“显示动态骨骼与碰撞体”，实时播放与暂停调参时均显示当前模拟骨骼、碰撞体及链名；关闭显示开关只隐藏提示，不停止求解。沿用穿透模型显示和远处混入灰色的深度提示。离线生成、烘焙和防穿运算期间仍暂停绘制。

每一条已配置链的每一节均求解，包括末节。`gravity_power=0`无重力，`weight=0`旁路；方向已与重力平行且处于平衡时，不一定发生明显旋转。网格跟随仍依赖实际蒙皮权重。

同一时刻只有一个角色拥有实时会话；停止后可切换角色。实时开启期间禁用离线生成和防穿任务，链结构或碰撞绑定变化需要重新开启。保存、加载、撤销、渲染、注销和目标失效会自动停止，保存文件不自动开启实时。

## 机制与范围

```text
基础Action的临时副本 -> 隐藏采样骨架 -> 60Hz现有链求解 -> 临时Pose
关闭预览            -> 恢复进入前Action -> 删除副本和隐藏骨架
```

临时副本修复反号四元数；原始曲线不修改。基础动作由当前Action读取；若当前是插件生成结果，通过明确输入元数据或基础动作指针解析原动作。停止时仍恢复原先选中的结果，不将实时状态当作正式烘焙输出。

球/胶囊代理体、锥限制与离线模拟共享求解函数。完整裙面防穿不在实时回调运行，不保证实时网格零穿模。FBX仍使用离线烘焙结果；导出前关闭实时预览。旧离线缩放/骨长等限制保持，修复了“关闭NLA但存在轨道仍被拒绝”的误判。

支持单槽完整Action、没有约束/驱动的已烘焙骨架、正统一缩放及标准继承。允许基础动作的平移和正统一骨骼缩放，按基础姿势更新每节当前长度；不修改Rest。非统一缩放、剪切、活动NLA和编辑模式拒绝或停止。外部切换Action时保留新选择，不写回旧Action；这是失效停止，不是跨插件全局锁。

真实时间线变化使用帧率换算60Hz固定步；每次最多追16步，倒放、循环和大跳帧重置状态。暂停用主线程timer推进。帧回调不调用`scene.frame_set`采样；隐藏骨架隔离输入，重复同帧不增加积分。停止恢复所需的一次求值在移除实时回调后执行。

## 正式量化入口

`tests/run_spring_bone_realtime_audit.py`提供`audit_realtime(folder)`，在BlenderMCP主线程调用。它检查：32节方向变化、实际蒙皮顶点移动、源曲线/Rest/权重保持、参数恢复、更新耗时。测试使用重力20的正反方向压力对照，结束恢复用户参数；压力对照位移不是默认参数效果。

同时检查手部保护：现有hand.L/hand.R及其后代任一权重大于1e-8的顶点，在重力压力对照中位移必须小于1e-6米。只验证裙摆有移动不能算通过。用户当前模型因历史误配重导致的手部问题已精确回退；旧防穿结果因此失效，不重新作为成品使用。

`tests/test_spring_bone_realtime.py`覆盖真实frame_change事件、暂停参数、球/胶囊、0混合、帧间无反馈、24/60FPS移动锚点、循环/跳帧、动作切换、删除目标、多角色、禁用NLA轨道、卸载和资源恢复。

`tests/run_spring_bone_realtime_file_lifecycle.py`在独立后台进程验证真实保存及重新打开文件，无需操作用户未保存场景。

统计标记`diagnostics_enabled`仅供正式量化，默认关闭。关闭时不计数、不收集耗时、不打印日志；审计脚本临时开启并恢复。核心帧回调、暂停timer、采样骨架和Action副本是实时功能资源，关闭实时后全部释放。

## 已测边界

Blender5.1.2真实角色，八条四节链共32节均响应方向改变。原生播放2.2秒约52个不同帧事件，约143个固定步，包含循环；0–52帧全段检查每帧均求解32节。两个裙面实际顶点随重力压力对照移动，静态数据不变。

重载前后实时统计可能因系统负载变化；参考已保存证据，中位更新约6ms、P95约10ms，偶发单次超过16ms，仍保留性能Concern。初次复制/预热不是每帧预算。本功能不宣称任意机器和复杂骨架恒定60FPS。

完整结果与清理状态见`docs/superpowers/evidence/2026-10-26-spring-bone-realtime/result.md`。
